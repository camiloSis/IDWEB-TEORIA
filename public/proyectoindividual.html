🚀 Mis Proyectos

📌 Proyecto 1: Portafolio Web Personal (este proyecto)

Aplicación web personal desarrollada desde cero como proyecto final del curso de Desarrollo Web. Integra todas las tecnologías aprendidas en un solo sistema funcional.

Tecnologías Utilizadas:

  • Frontend: HTML con estructura semántica, CSS con diseño responsive usando Flexbox y Grid
  • JavaScript: Sistema de navegación por pestañas, validación de formularios en tiempo real, animaciones y efectos interactivos
  • Backend: Servidor HTTP en Python puro (http.server o wsgiref.simple_server) con manejo manual de rutas
  • Base de Datos: MySQL para almacenar mensajes de contacto con consultas y panel de administración

Características Principales:

  1. Diseño completamente responsive que se adapta a móviles, tablets y desktop
  2. Sistema de navegación dinámico entre 5 secciones sin recargar la página
  3. Formulario de contacto con validación en tiempo real y envío al servidor
  4. Panel de administración protegido por contraseña para gestionar mensajes
  5. Código limpio, comentado y alojado en repositorio GitHub público

Estado: ✅ Terminado - 100% completado

Repositorio: https://github.com/camiloSis/IDWEB-TEORIA
